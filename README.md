Simple Calculator

A simple and beginner-friendly calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division.


Features

Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Clear (C) button
Equal (=) button to calculate results
Simple and responsive calculator layout
Hover effects on calculator buttons
Clean and minimal user interface

Technologies Used

HTML5 – Creates the calculator structure and buttons.
CSS3 – Provides styling, layout, colors, and button effects.
JavaScript – Handles calculator input and calculations.

How It Works

The calculator uses an input field as its display.

When a number or operator button is clicked, its value is added to the display.


How to Run

Download or clone this repository.
Open the project folder.
Make sure index.html, style.css, and script.js are in the same folder.
Open index.html in any modern web browser.
Start using the calculator.
